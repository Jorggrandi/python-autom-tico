# Módulo sobre manipulação de STRINGS. 

-> lower() : deixa a string em lower case
-> upper() : deixa a sring em upper case
-> string[x] : mostra o caracter no index x 
-> .len() : mostra o tamanho da string
-> capitalize() : deixa a primeira letra da frase em maíusculo
-> find[x] : acha a posição do dígito x
-> string[0:9] : acha as letras de 1 à 10
-> count(x) : conta quantas vezes o caracter x aparece
-> strip() : apaga os espaços nas laterais
-> title : deixa as primeiras letras de todas as palavras maísculas
-> replace(x,y) : troca o dígito x por y

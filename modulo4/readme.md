# Módulo sobre LISTAS e DICIONÁRIOS

## Listas

-> `lista[-1]` : acessa o último elemento da lista usando índice negativo
-> `lista[0]` : acessa o primeiro elemento da lista usando índice positivo
-> `lista.append(item)` : adiciona um item ao final da lista
-> `lista.remove(item)` : remove o item especificado da lista
-> `lista[índice] = valor` : modifica o elemento no índice especificado
-> `len(lista)` : retorna o tamanho/quantidade de elementos da lista
-> `lista.count(item)` : conta quantas vezes um item aparece na lista
-> `lista.index(item)` : retorna o índice da primeira ocorrência do item
-> `for item in lista:` : itera sobre todos os elementos da lista

## Tuplas

-> `tupla = (item1, item2, item3)` : cria uma tupla com elementos imutáveis
-> `tupla[0]` : acessa o elemento no índice especificado
-> `tupla[-1]` : acessa o último elemento usando índice negativo
-> `len(tupla)` : retorna o tamanho/quantidade de elementos da tupla
-> `tupla.count(item)` : conta quantas vezes um item aparece na tupla
-> `tupla.index(item)` : retorna o índice da primeira ocorrência do item
-> Tuplas são imutáveis: não podem ser modificadas após criação (diferente de listas)

## Dicionários

-> `dicionário = {chave: valor}` : cria um dicionário com pares chave-valor
-> `dicionário['chave']` : acessa o valor associado à chave
-> `dicionário['nova_chave'] = novo_valor` : adiciona ou modifica um par chave-valor

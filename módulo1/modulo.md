# Módulo - Conceitos iniciais

Nesse módulo aprendi os seguintes conteúdos.

print : printa informações e dados no terminal
variáveis : são uma caixinha na memoria que guardam dados

tipos de dados:
 - String: Texto
 - Int: Números inteiros
 - Float: números com ,

operações: 
 + : soma
 - : subtração
 / : divisão
 * : multiplicação
 ** : exponenciação
 % : divisão do que sobrou no repartimento
 // : divisão inteira ( 7/2 ) = 3
 

fString:
 - colocar um f antes de uma string faz ela poder usar pedaços de código tipo variavéis.
 - ex -> print(f"Sua média é de {result}, estude mais garoto!")

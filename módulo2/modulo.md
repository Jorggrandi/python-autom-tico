# Módulo - Condicionais 

Nesse módulo eu aprendi:

## Lógica
 - if -> compara alguma expressão para montar um fluxo
 - elif -> segunda condição se não passar da primeira
 - else -> else se não se enquadrar em determinada condição

## Match Case
- serve para avaliar várias expressões 
- estrutura:
    match variável:
        case x: print
        case y: print
        case _: se não cair em nenhuma expressão

## Comparação
- < menor 
- <= menor ou igual
- > maior
- >= maior ou igual
- == compara igualdade
- != compara diferença

## Outras paradas
- or : se algo for x OU y
- and:  se algo x for correto e y também
- not: senão estiver/for
